# Polymarket CLOB Authentication (offline reference)

> Source: https://docs.polymarket.com/developers/CLOB/authentication
> Saved: 2026-05-02

The CLOB API uses two levels of authentication: **L1 (Private Key)** and **L2 (API Key)**.

## Public vs Authenticated

- **Public (No Auth)**: Gamma API, Data API, and CLOB read endpoints (orderbook, prices, spreads).
- **Authenticated (CLOB)**: trading endpoints (placing orders, cancellations, heartbeat) require all 5 `POLY_*` L2 HTTP headers.

## Two-Level Auth Model

### L1 (Private Key)

Wallet signs an EIP-712 message used in the request header. Used for:
- Creating API credentials (`POST /auth/api-key`)
- Deriving existing API credentials (`GET /auth/derive-api-key`)
- Signing user's orders locally

### L2 (API Key)

Uses the `apiKey`, `secret`, `passphrase` triple generated from L1. HMAC-SHA256 signs each request. Used for:
- Cancel / get user's open orders
- Check user's balances and allowances
- Post user's signed orders

## L1 Headers

| Header           | Description            |
| ---------------- | ---------------------- |
| `POLY_ADDRESS`   | Polygon signer address |
| `POLY_SIGNATURE` | CLOB EIP-712 signature |
| `POLY_TIMESTAMP` | Current UNIX timestamp |
| `POLY_NONCE`     | Nonce (default: 0)     |

The `POLY_SIGNATURE` is generated by signing this EIP-712 struct:

```ts
const domain = {
  name: "ClobAuthDomain",
  version: "1",
  chainId: 137,
}
const types = {
  ClobAuth: [
    { name: "address",   type: "address" },
    { name: "timestamp", type: "string"  },
    { name: "nonce",     type: "uint256" },
    { name: "message",   type: "string"  },
  ],
}
const value = {
  address: signingAddress,
  timestamp: ts,
  nonce,
  message: "This message attests that I control the given wallet",
}
```

Reference impls:

- Python: https://github.com/Polymarket/py-clob-client-v2/blob/main/py_clob_client_v2/signing/eip712.py

## L2 Headers (5 required on every trading request)

| Header            | Description                   |
| ----------------- | ----------------------------- |
| `POLY_ADDRESS`    | Polygon signer address        |
| `POLY_SIGNATURE`  | HMAC signature for request    |
| `POLY_TIMESTAMP`  | Current UNIX timestamp        |
| `POLY_API_KEY`    | User's API `apiKey` value     |
| `POLY_PASSPHRASE` | User's API `passphrase` value |

HMAC reference impls:
- TypeScript: https://github.com/Polymarket/clob-client-v2/blob/main/src/signing/hmac.ts
- Python: https://github.com/Polymarket/py-clob-client-v2/blob/main/py_clob_client_v2/signing/hmac.py

Local impl matching: `src/lib/hmac.ts`.

## Signature Types and Funder

When initializing the L2 client, specify wallet `signatureType` and `funder`:

| Signature Type | Value | When                                                                      |
| -------------- | ----- | ------------------------------------------------------------------------- |
| EOA            | `0`   | Standard Ethereum wallet (MetaMask). Funder = EOA. Needs POL for gas.     |
| POLY_PROXY     | `1`   | Magic Link / email login proxy wallet. User must export PK from Polymarket. |
| GNOSIS_SAFE    | `2`   | Gnosis Safe multisig. **Most common** for new/returning users.            |

The wallet shown to the user on Polymarket.com is the proxy wallet — that's the `funder`.

## Known operational gotcha (relevant to our app)

`POST /auth/api-key` is hard-protected by Cloudflare WAF — server-side requests from datacenter IPs return 403 with the "Attention Required!" HTML challenge regardless of the User-Agent or other headers. Verified 2026-05-01: 20/20 attempts blocked from local IP, 20/20 blocked from Vercel. Read endpoints (`GET /markets`, `POST /prices`) and L2 endpoints (`/data/orders`, `/balance-allowance`) pass through fine.

Workaround in our app: route CLOB through a Cloudflare Worker pass-through (`workers/clob-proxy/`, deployed as `axes-clob-proxy.direct-axes.workers.dev`). When paired with the full browser-style headers our `polymarketUpstreamFetch` sends (Origin, Referer, Sec-Fetch-*, Sec-Ch-Ua-*), the WAF passes the request through. Documented in `Polymarket/py-clob-client#91` (open since 2024-08).

## Troubleshooting (from upstream docs)

| Error               | Cause                                | Fix                                                |
| ------------------- | ------------------------------------ | -------------------------------------------------- |
| `INVALID_SIGNATURE` | wallet PK invalid or wrong format    | verify hex string, correct key, permissions       |
| `NONCE_ALREADY_USED`| nonce already created an API key     | use `deriveApiKey()` w/ same nonce, OR new nonce  |
| `Invalid Funder`    | funder doesn't match wallet          | check polymarket.com/settings, deploy proxy first  |
| Lost creds + nonce  | unrecoverable                        | create fresh credentials with new nonce            |

## V2 Order wire body (clob-client-v2 `client.ts createAndPostOrder`)

The SDK signs the 11-field V2 struct, then wraps in:

```json
{
  "deferExec": false,
  "order": {
    /* the 11 signed fields */
    "salt": "...", "maker": "0x...", "signer": "0x...",
    "tokenId": "...", "makerAmount": "...", "takerAmount": "...",
    "side": "BUY" | "SELL",
    "signatureType": 0 | 1 | 2 | 3,
    "timestamp": "...",
    "metadata": "0x000...000",  // bytes32, default zero
    "builder":  "0x23a45b95...", // bytes32, builder code or zero
    "signature": "0x...",        // 65-byte ECDSA or EIP-1271
    "expiration": "0"            // wire-only, not signed
  },
  "owner": "<api_key_uuid>",
  "orderType": "GTC" | "GTD" | "FOK" | "FAK",
  "postOnly": false
}
```

Per `clob-client-v2/src/client.ts`:
```ts
if (this.builderConfig?.builderCode && !orderToSign.builderCode) {
  orderToSign.builderCode = this.builderConfig.builderCode;
}
```

Builder code injected automatically by the SDK if configured.

## Authentication schemes — final verbatim

From `docs.polymarket.com/api-reference/authentication`:

> "Two authentication levels exist:"
> - L1: EIP-712 signing with private key (for creating/deriving API keys)
> - L2: HMAC-SHA256 with API key, secret, passphrase (for trading)

### L1 headers (POST `/auth/api-key` and `/auth/builder-api-key`)
- `POLY_ADDRESS`
- `POLY_SIGNATURE` ← EIP-712 signature of `ClobAuth` typed data
- `POLY_TIMESTAMP`
- `POLY_NONCE`

### L2 headers (everything else with auth)
- `POLY_ADDRESS`
- `POLY_API_KEY`
- `POLY_PASSPHRASE`
- `POLY_SIGNATURE` ← HMAC of `timestamp+method+path+body`
- `POLY_TIMESTAMP`

### Builder attribution headers (added to L2)
From `Polymarket/builder-signing-sdk/src/signer.ts`:
- `POLY_BUILDER_API_KEY`
- `POLY_BUILDER_PASSPHRASE`
- `POLY_BUILDER_SIGNATURE` ← HMAC with builder secret
- `POLY_BUILDER_TIMESTAMP`

### Relayer headers (POST `/submit` and friends — choose ONE method)

**Builder API Key auth (full HMAC):**
- `POLY_BUILDER_API_KEY`, `POLY_BUILDER_TIMESTAMP`, `POLY_BUILDER_PASSPHRASE`, `POLY_BUILDER_SIGNATURE`

**Relayer API Key auth (simpler, no HMAC):**
- `RELAYER_API_KEY`
- `RELAYER_API_KEY_ADDRESS`

We use the simpler one (verified live this session).
